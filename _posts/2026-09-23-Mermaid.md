A short note demonstrating how to embed a **Mermaid flow chart** and math in a post.

## Mermaid flow chart

To show a Mermaid diagram, just use a fenced code block with the `mermaid` language tag:

````
```mermaid
flowchart LR
    A[Start] --> B{Decision}
    B -->|Yes| C[Do this]
    B -->|No| D[Do that]
    C --> E[End]
    D --> E
```
````

Which renders as:

```mermaid
flowchart LR
    A[Start] --> B{Decision}
    B -->|Yes| C[Do this]
    B -->|No| D[Do that]
    C --> E[End]
    D --> E
```

## Markov chain example

```mermaid
flowchart LR
    past["⋯"] --> xm(("xₜ₋₁"))
    xm --> xt(("xₜ"))
    xt --> xp(("xₜ₊₁"))
    xp --> future["⋯"]

    um(("uₜ₋₁")) --> xm
    ut(("uₜ")) --> xt
    up(("uₜ₊₁")) --> xp

    xm --> zm(("zₜ₋₁"))
    xt --> zt(("zₜ"))
    xp --> zp(("zₜ₊₁"))
```

## Math

$$
\begin{bmatrix} x_k \\ z_k \end{bmatrix}
\;\big|\;
z_{1:k-1},u_{1:k}
\sim
\mathcal N\left(
\begin{bmatrix}
\bar\mu_k\\
H_k\bar\mu_k
\end{bmatrix},
\begin{bmatrix}
\bar\Sigma_k&\bar\Sigma_kH_k^\top\\
H_k\bar\Sigma_k&H_k\bar\Sigma_kH_k^\top+Q_k
\end{bmatrix}
\right).
$$
